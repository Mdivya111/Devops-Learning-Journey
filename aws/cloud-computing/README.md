# AWS Cloud Computing

## What I Learned

Cloud computing means using computing resources such as servers, storage, networking, and databases over the internet instead of maintaining physical infrastructure ourselves.

AWS provides these cloud resources on demand.

## Key Concepts

### On-Premises vs Cloud

In an on-premises environment, an organization owns and manages its physical servers, networking equipment, storage, and data center infrastructure.

In a cloud environment, these resources are provided by a cloud provider such as AWS and can be provisioned when required.

### IaaS

Infrastructure as a Service provides infrastructure resources such as virtual machines, storage, and networking.

**Example:** Amazon EC2.

### PaaS

Platform as a Service provides a managed platform where developers can deploy applications without managing the underlying infrastructure.

### SaaS

Software as a Service provides ready-to-use software applications over the internet.

### Public Cloud

Cloud infrastructure is provided by a cloud provider and shared among multiple customers while each customer's resources remain logically isolated.

**Example:** AWS.

### Private Cloud

Cloud infrastructure is dedicated to a single organization.

### Hybrid Cloud

A hybrid cloud combines on-premises infrastructure with cloud infrastructure.

### Scalability

Scalability is the ability of a system to handle increased workload by adding or removing resources.

### Elasticity

Elasticity is the ability to automatically adjust resources according to workload demand.

### High Availability

High availability means designing systems to remain operational and accessible even when individual components fail.

### Fault Tolerance

Fault tolerance is the ability of a system to continue operating when a component fails.

### Pay-as-You-Go

Cloud services generally follow a usage-based pricing model, where customers pay for the resources they use rather than purchasing and maintaining all infrastructure upfront.

## DevOps Relevance

Cloud computing is important in DevOps because it provides on-demand infrastructure for:

- Application deployment
- CI/CD pipelines
- Testing environments
- Infrastructure automation
- Containerized applications
- Monitoring
- Scalable applications

A DevOps engineer commonly uses cloud services to provision infrastructure, deploy applications, automate operations, and scale systems.

## AWS Example

A basic cloud-based application can use:

**User → Load Balancer → EC2 → EBS**

AWS provides the infrastructure required to run and manage these components without the organization owning the physical servers.
