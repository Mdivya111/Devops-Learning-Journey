## Key Concepts

### AWS

AWS provides cloud-based services such as compute, storage, networking, databases, security, monitoring, and automation.

### Region

An AWS Region is a geographical area that contains multiple isolated Availability Zones.

### Availability Zone

An Availability Zone is an isolated location within an AWS Region that contains one or more data centers.

Using multiple Availability Zones can improve application availability and fault tolerance.

### Scalability

Scalability is the ability of a system to handle increasing workload by increasing or decreasing resources as required.

### Elasticity

Elasticity is the ability to automatically adjust resources according to workload demand.

### High Availability

High availability means designing systems to remain accessible and operational even when individual components fail.

### Fault Tolerance

Fault tolerance is the ability of a system to continue operating when a component or resource fails.

## DevOps Relevance

AWS is commonly used in DevOps for:

- Cloud infrastructure
- Application hosting
- Compute resources
- Storage
- Networking
- Load balancing
- Automation
- CI/CD
- Monitoring
- Infrastructure as Code

AWS provides the infrastructure on which DevOps tools and deployment workflows can operate.

## Learning Approach

My AWS learning focuses on understanding the concepts first and then applying them through practical hands-on work.

Cost awareness is important because some AWS resources can generate charges even when used for learning. I therefore prioritize Free Tier-eligible resources and clean up resources after practical exercises.
