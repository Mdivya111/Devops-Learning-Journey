## Key Concepts

### Linux Filesystem

Linux organizes files and directories in a hierarchical filesystem starting from the root directory `/`.

### Absolute and Relative Paths

An absolute path starts from `/`, while a relative path is based on the current working directory.

### File Permissions

Linux permissions control access for:

- User/owner
- Group
- Others

The three basic permissions are:

- `r` — read
- `w` — write
- `x` — execute

### chmod

`chmod` is used to change file or directory permissions.

Permissions can be specified using numeric values or symbolic notation.

### Ownership

Linux files have an owner and a group.

`chown` changes ownership, while `chgrp` changes group ownership.

### Symbolic Links

A symbolic link is a reference to another file or directory.

It is similar to a shortcut and can point to a target located elsewhere in the filesystem.
